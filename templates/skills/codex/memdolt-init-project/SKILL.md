# Initialize project memory

Read and follow the [shared onboarding procedure](../../memdolt-resources/onboarding.md). Resolve that path
relative to this installed file, never the project's working directory. If it
is missing, stop and report the incomplete workflow installation.

Use `--actor "codex"` for narrative and other permitted CLI memory writes;
this normalizes to `agent:codex`. Never use `--actor user` to bypass review.
The procedure requires an explicitly selected repository and authoritative
memory system before setup. It preserves existing memory and host settings.
