# Catch up project memory

Read and follow the [shared catch-up procedure](../../memdolt-resources/catch-up.md).
Resolve that path relative to this installed file, never the project's working
directory. If it is missing, stop and report the incomplete installation.

Use the selected repository and authoritative memory system. Honor existing
catch-up authorization; conflicts still require actual human choices. Preserve
confirmed effects and stop dependent work on partial or unknown outcomes.
